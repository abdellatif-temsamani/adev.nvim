# Improve adev-files Keymaps

## Goal
Redesign keymaps for the adev-files floating file manager to be more vim-like, intuitive, and consistent. Keep `<bs>` (parent dir) and `<esc>` (close help/dialog) unchanged as requested.

## Files to Modify

1. **`/home/flagmate/.config/nvim/lua/adev-files/events/keymaps.lua`** - Main keymap definitions
2. **`/home/flagmate/.config/nvim/lua/adev-files/help.lua`** - Help text and compact header

## Current Issues

- `K` and `J` are disabled (`<nop>`) - wasted key bindings
- `<leader>bq` and `<leader>n` are disabled - leader keymaps feel out of place in a floating buffer
- `P` (uppercase) for paste is less vim-like than `p` (lowercase)
- `U` for revert conflicts with vim's `U` (undo line changes)
- `yc` for clear clipboard is awkward and non-mnemonic
- No keymap for refreshing the view
- No keymap for creating new files (must type manually)

## Proposed Keymap Changes

### Navigation (mostly keep, minor improvements)
| Current | New | Action |
|---------|-----|--------|
| `<CR>` | `<CR>` | Open file / enter directory (keep) |
| `L` | `l` | Open file / enter directory (change to lowercase for consistency) |
| `<Right>` | `<Right>` | Open file / enter directory (keep) |
| `H` | `h` | Go to parent directory (add `h` like vim left) |
| `<Left>` | `<Left>` | Go to parent directory (keep) |
| `<BS>` | `<BS>` | Go to parent directory (keep unchanged) |
| `q` | `q` | Quit (keep) |

### Clipboard (improve)
| Current | New | Action |
|---------|-----|--------|
| `yy` | `yy` | Copy (keep, vim-standard) |
| `dd` | `dd` | Cut (keep, vim-standard) |
| `P` | `p` | Paste (change to lowercase, more vim-like) |
| `yc` | `cc` | Clear clipboard (change to "clear-clear" mnemonic) |

### Delete & Revert
| Current | New | Action |
|---------|-----|--------|
| `D` | `D` | Delete (keep) |
| `U` | `u` | Revert current line (change to lowercase `u` for undo) |

### New Operations
| Key | Action |
|-----|--------|
| `R` | Refresh view (re-read directory) |
| `a` | Create new file/directory (type name, append) |

### Removed
- Remove `<nop>` for `K`, `J`, `<leader>bq`, `<leader>n` - just don't bind them
- Remove `L` (use `l` instead)
- Remove `H` (use `h` instead)

### New keymap: Refresh (R)
```lua
set_keymap("n", "R", function()
    local state = require "adev-files.state"
    local root = state.get_root(buf)
    if root then
        require("adev-files.sync").refresh(buf, root)
    end
end)
```

### New keymap: Create new file (a)
```lua
set_keymap("n", "a", function()
    vim.cmd "startinsert"
    -- Position cursor at end of buffer on a new line
    local line_count = vim.api.nvim_buf_line_count(buf)
    vim.api.nvim_win_set_cursor(0, { line_count + 1, 0 })
    vim.api.nvim_feedkeys("o", "n", false)
end)
```
